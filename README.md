**Healthcare Data Analysis Using MySQL**

Analyzed healthcare data using MySQL to explore patient demographics, medical conditions, billing details, hospital performance, doctor workloads, and length of hospital stays. Used SQL queries, aggregate functions, `GROUP BY`, `CASE`, sorting, and date calculations to identify trends and generate meaningful insights.

**Tools:** MySQL  
**Skills:** SQL Queries, Data Analysis, Aggregation, Data Grouping, Filtering, and Date Functions
